# University Management System

A lightweight, console-based university management application built with C# on .NET 10 to manage academic administration workflows, course scheduling, and student information.

## Features
- **Student Administration:** Maintain student profiles, enrollment statuses, and personal records.
- **Course & Department Organization:** Track course offerings, prerequisites, and department allocations.
- **Console Interface:** Clean, menu-driven command-line interface for efficient data entry and administrative operations.
- **Modern .NET 10 Architecture:** Fast execution and lightweight deployment targeting modern .NET runtime primitives.

## Tech Stack
- **Language:** C#
- **Platform:** .NET 10.0
- **Project Type:** Console Application
- **IDE:** Visual Studio / VS Code
